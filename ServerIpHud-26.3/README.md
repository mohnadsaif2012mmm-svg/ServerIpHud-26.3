# Server IP HUD (Fabric 26.3)
Shows the server IP in the top-left corner of the screen (multiplayer only, hidden with F1).

Needs: Minecraft 26.3, Fabric Loader 0.19.5+, Fabric API 0.161.0+26.3, Java 25.

Build with GitHub Actions: push to GitHub -> Actions tab -> "Build mod" -> download the artifact.
